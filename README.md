
# Smart City Traffic Intelligence – NUS Capstone

## Project Overview
This repository contains the Smart City Traffic Intelligence Capstone developed as part of the NUS AI, Machine Learning and Data Science programme.

The project uses the Metro Interstate Traffic Volume dataset to analyse traffic patterns, explore relationships between weather and congestion, build reproducible data-processing workflows, and develop machine learning applications.

## Project Objectives
- Analyse historical traffic patterns and congestion.
- Investigate weather, temperature and temporal factors influencing traffic.
- Apply statistical and probability-based analysis.
- Develop interactive Power BI dashboards.
- Build a reproducible Python data pipeline and command-line application.
- Extend the project through machine learning, evaluation and responsible AI practices.

## Project Structure

- `powerbi/`: Power BI traffic intelligence dashboard.
